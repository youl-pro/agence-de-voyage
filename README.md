# Agence de Voyage 🌍

## Présentation

**Agence de Voyage** est un projet de site web vitrine réalisé dans le cadre de ma pratique du développement web.

L'objectif est de présenter une agence de voyage à travers une interface simple et agréable, permettant aux visiteurs de découvrir des offres et de contacter l'agence.

## Technologies utilisées

- **HTML5** : structure des pages.
- **CSS3** : mise en forme et design.
- **JavaScript** : interactions et fonctionnalités.

## Fonctionnalités

- Présentation de l'agence de voyage.
- Formulaire de contact.
- Images illustrant les destinations et les services.

## Installation et utilisation

1. Cloner le dépôt :

   ```bash
   git clone https://github.com/youl-pro/agence-de-voyage.git
   ```

2. Ouvrir le dossier du projet.
3. Ouvrir le fichier `index.html` dans un navigateur web.
